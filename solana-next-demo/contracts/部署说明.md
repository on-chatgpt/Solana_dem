# Solana质押程序部署说明

## 项目概述

这是一个Solana链上的HHF代币质押程序，支持以下功能：
- **质押HHF代币**：用户可以将HHF代币质押到程序中
- **领取利息**：每分钟0.1%的利息，用户可以随时领取已产生的利息
- **全部领取**：用户可以同时领取利息和本金

## 程序架构说明

### 核心概念

1. **质押池账户（StakePool）**
   - 类型：PDA账户（Program Derived Address）
   - 作用：存储全局质押池状态
   - 包含信息：
     - `authority`: 管理员地址
     - `token_mint`: HHF代币的mint地址
     - `interest_token_account`: 利息池代币账户地址
     - `stake_token_account`: 质押代币账户地址
     - `total_staked`: 总质押量
     - `bump`: PDA的bump seed

2. **用户质押账户（UserStake）**
   - 类型：PDA账户（每个用户一个）
   - 作用：存储用户的质押信息
   - 包含信息：
     - `user`: 用户地址
     - `stake_pool`: 质押池地址
     - `staked_amount`: 质押金额
     - `stake_time`: 首次质押时间
     - `last_update_time`: 最后更新时间
     - `accrued_interest`: 已累计但未领取的利息
     - `bump`: PDA的bump seed

3. **质押代币账户（stake_token_account）**
   - 类型：SPL Token账户
   - Authority：stake_pool PDA
   - 作用：存储所有用户质押的HHF代币
   - 说明：用户质押时，代币从用户账户转移到这个账户

4. **利息池代币账户（interest_token_account）**
   - 类型：SPL Token账户
   - Authority：stake_pool PDA
   - 作用：存储用于支付利息的HHF代币
   - 说明：
     - 用户领取利息时，代币从这个账户转移到用户账户
     - 管理员需要预先向这个账户存入足够的HHF代币
     - **注意**：如果使用相同的mint和owner，这个账户可能与stake_token_account是同一个账户

### 账户关系图

```
管理员 (authority)
  │
  ├─> 初始化质押池
  │
  └─> 存入HHF代币到利息池账户（用于支付利息）

质押池PDA (stake_pool)
  │
  ├─> 质押代币账户 (stake_token_account)
  │   └─> 存储用户质押的HHF代币
  │
  └─> 利息池代币账户 (interest_token_account)
      └─> 存储用于支付利息的HHF代币
          （可能与stake_token_account是同一个账户）

用户 (user)
  │
  ├─> 质押HHF代币
  │   └─> 从用户账户 → stake_token_account
  │
  ├─> 领取利息
  │   └─> 从interest_token_account → 用户账户
  │
  └─> 全部领取（本金+利息）
      ├─> 从stake_token_account → 用户账户（本金）
      └─> 从interest_token_account → 用户账户（利息）
```

### 利息计算

- **利率**：每分钟0.1%（即0.001）
- **计算公式**：`利息 = 本金 × 0.001 × 分钟数`
- **示例**：
  - 质押1000个HHF代币
  - 1分钟后：利息 = 1000 × 0.001 × 1 = 1个HHF
  - 10分钟后：利息 = 1000 × 0.001 × 10 = 10个HHF
  - 60分钟后：利息 = 1000 × 0.001 × 60 = 60个HHF

## 部署步骤

### 前置要求

1. **安装依赖**
   ```bash
   # 确保已安装Anchor框架
   anchor --version
   
   # 安装Node.js依赖
   pnpm install
   ```

2. **配置Solana钱包**
   ```bash
   # 确保你的Solana钱包有足够的SOL（用于支付交易费用）
   solana balance
   
   # 如果余额不足，可以领取测试SOL
   solana airdrop 2
   ```

3. **准备HHF代币**
   - 确保你有HHF代币的mint地址
   - 确保你的钱包中有一些HHF代币（用于存入利息池）

### 部署程序

1. **构建程序**
   ```bash
   anchor build
   ```

2. **部署到开发网络（devnet）**
   ```bash
   anchor deploy
   ```

3. **运行初始化脚本**
   ```bash
   # 首先，编辑 migrations/deploy.ts 文件
   # 将 YOUR_HHF_TOKEN_MINT_ADDRESS_HERE 替换为你的HHF代币mint地址
   
   # 然后运行初始化脚本
   anchor run setup
   # 或者
   npx ts-node -T --compiler-options '{"types":["node"],"lib":["es2020"]}' ./migrations/deploy.ts
   ```

### 初始化脚本说明

初始化脚本会执行以下操作：

1. **计算质押池PDA地址**
   - 使用seed `"stake_pool"` 和程序ID计算PDA

2. **创建代币账户**
   - 创建质押代币账户（authority是stake_pool PDA）
   - 创建利息池代币账户（authority是stake_pool PDA）
   - 注意：如果两个账户使用相同的mint和owner，它们会是同一个账户

3. **初始化质押池**
   - 调用程序的`initialize`函数
   - 设置代币mint地址
   - 设置代币账户地址

4. **（可选）存入利息资金**
   - 你可以手动向利息池账户存入HHF代币
   - 或者修改脚本，添加自动转账功能

### 向利息池存入代币

在用户开始质押之前，你需要确保利息池账户中有足够的HHF代币用于支付利息。

**方法1：使用Solana CLI**
```bash
# 获取利息池账户地址（从初始化脚本的输出中获取）
# 然后使用spl-token转账
spl-token transfer <HHF_TOKEN_MINT> <数量> <利息池账户地址>
```

**方法2：使用程序或脚本**
你可以创建一个管理函数来向利息池存入代币，或者直接使用spl-token CLI工具。

## 重要注意事项

1. **利息池资金管理**
   - 确保利息池账户中有足够的HHF代币
   - 如果资金不足，用户将无法领取利息
   - 建议定期检查并补充利息池资金

2. **代币账户设计**
   - 如果质押代币账户和利息池代币账户是同一个账户，所有代币都在一个账户中
   - 程序通过逻辑来区分质押本金和利息资金
   - 确保账户总余额 >= 总质押量 + 预计利息

3. **安全性**
   - 质押池的authority是管理员，可以修改配置（如果需要添加此功能）
   - 代币账户的authority是PDA，只有程序可以控制
   - 用户只能操作自己的质押记录

4. **测试建议**
   - 在devnet上充分测试
   - 测试各种边界情况（零质押、大额质押、频繁领取等）
   - 确保利息计算正确

## 常见问题

**Q: 如何计算用户质押账户的PDA？**
A: 使用以下seed计算：
```typescript
const [userStakePda] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("user_stake"),
    userPublicKey.toBuffer(),
    stakePoolPda.toBuffer(),
  ],
  programId
);
```

**Q: 如果利息池资金不足怎么办？**
A: 程序会返回`InsufficientInterestFunds`错误。管理员需要向利息池账户存入更多HHF代币。

**Q: 可以修改利率吗？**
A: 当前版本利率硬编码为每分钟0.1%。如果需要可配置的利率，可以添加一个管理函数来修改。

**Q: 如何查询用户的质押信息？**
A: 使用Anchor的`fetch`方法：
```typescript
const userStake = await program.account.userStake.fetch(userStakePda);
```
